# Итоговый отчёт Codex — обязательная структура

## Что изменилось для бизнеса центра

Показать результат отдельно для оператора, руководителя и заказчика. Описать простой документ, повторный заказ, согласование изменений, получение готового комплекта, поиск истории и контроль незавершённых действий. Для каждого показать исчезнувшую ручную работу и оставшиеся ограничения. Нагрузочный путь на 100 человек — отдельный пример, не главная цель.

## Повседневные сценарии V01–V12

Для каждого: фактические шаги, бизнес-результат, BV ID, AT ID, измерения/доказательства либо точная причина непройденной проверки. Нет измеренного baseline — нет процента экономии. Подробности — BusinessValueEvidence.md.

## Полнота F01–F32

Для каждой функции: состояние реализации, пути UI/API/DB, тесты AT, доказательство, ограничения. Отдельно статус «проверено runtime/визуально», а не только «файл существует».

## Фактические числа G1/G2

Ожидаемое и фактическое количество людей, назначений, документов/протоколов, номеров, файлов, повторных ручных действий. Ссылки на реальные синтетические комплекты, registry и screenshots.

## Изменения

Список файлов, миграций и контрактов; ADR; совместимость v1; изменения product-policy/AGENTS в пределах новой авторизации; подтверждение отсутствия разморозки DSJ.

## Проверки

Команды/exit codes/SHA; проваленные и повторённые проверки; доказательства исправления регрессии ITR registry; все неисполненные внешние проверки.

## Эксплуатация

Запуск/конфигурация без секретов, ограниченный onboarding, backup/restore, upgrade/rollback, объёмы, известные ограничения. Никаких выполненных production действий без отдельного разрешения.

## Четыре статуса подтверждения

Раздельно: реализация, инженерная проверка, пользовательское испытание и коммерческое подтверждение. Последние два не выдумывать по результатам build/e2e. Не называть преимущество уникальным без сравнения и спрос подтверждённым без данных.

## Готовность

Отдельно: готовность демонстрации; техническая готовность локального продукта; проверка конкретных рабочих форм; production. Не сводить их к общему «всё готово». Незавершённая обязательная функция не исчезает из отчёта.
