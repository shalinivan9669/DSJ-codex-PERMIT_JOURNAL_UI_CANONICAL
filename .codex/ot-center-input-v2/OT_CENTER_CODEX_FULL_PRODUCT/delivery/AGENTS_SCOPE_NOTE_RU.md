# Уточнение области для применимых AGENTS

Этот файл — текст решения для исполнителя, **не автоматически применяемый AGENTS.override.md**. Не копировать его поверх всех существующих инструкций. Прочитать реальные AGENTS и внести минимальное согласованное уточнение только в нужную область.

Текущая задача пользователя расширяет автономный DEMO административными функциями F01–F32: массовые общие данные, события/групповые протоколы, база людей, списки/согласование, выдача, исполнение заказов, повторные обращения, ограниченный работодатель, внешние подтверждения, досье и небольшой коммерческий слой. Разрешены необходимые новые модели/маршруты/права/тесты **в этом продукте**.

Замороженные DSJ журналы/наряды/LMS/signing/correspondence/notifications/старые workers остаются замороженными. Одноимённая потребность нового продукта не разрешает использовать их runtime код и полномочия. Имеющаяся политика deny-by-default расширяется точными capabilities, а не снимается. Требования безопасности, сохранности данных, юридической честности и запрет production вмешательства действуют полностью.

Передача одного полного объёма не требует отмены sandbox/approval или запуска опасных команд без согласия. Инженерный агент работает автономно над обратимыми изменениями и отдельно фиксирует внешние блокеры.
