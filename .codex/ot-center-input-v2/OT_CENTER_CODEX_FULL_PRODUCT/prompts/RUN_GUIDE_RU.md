# Запуск задания в Codex

Для непосредственной реализации достаточно одного основного промпта `01_CODEX_START_PROMPT_RU.md` и доступной распакованной папки. Выбрать нужный репозиторий/ветку и обычный режим выполнения изменений. Вставлять в чат все JSON и таблицы вручную не требуется: промпт направляет агента прочитать файлы.

Отдельный `PLAN_MODE_PROMPT_RU.md` предназначен только для предварительного планирования, когда пользователь намеренно выбрал такой режим. Он не обязателен перед основной задачей. После плана для реализации применяется основной промпт, а не ожидание, что план сам изменил код.

В `CONTINUE_PROMPT_RU.md` описано восстановление после реального прерывания по Progress/Decisions. Это не разделение функций на релизы. `INDEPENDENT_REVIEW_PROMPT_RU.md` проверяет результат и не принимает отчёт автора без воспроизведения.

Подход с сохранённой спецификацией, планом, состоянием и повторяющимися проверками описан OpenAI для долгих задач Codex: https://developers.openai.com/blog/run-long-horizon-tasks-with-codex . Прочитано 22.09.2026. Это метод организации работы, не обещание длительности или безлимитной сессии на конкретном тарифе.

Инструкции репозитория нужно читать и уточнять в их области, а не заменять большим handoff целиком: https://developers.openai.com/codex/guides/agents-md . Прочитано 22.09.2026. Этот пакет не меняет глобальную конфигурацию Codex, не предлагает отключать разрешения и не задаёт выдуманное имя модели.

Ссылки на документацию и даты чтения выше сохранены из исходного пакета. В этой редакции проводилась проверка файлов задания; актуальная документация сервисов и HEAD репозитория заново не исследовались.
