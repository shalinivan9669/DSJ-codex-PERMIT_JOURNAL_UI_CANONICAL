1619: ОРГАНИЗАЦИИ
1620: → ДОБАВИТЬ СОТРУДНИКОВ
1621: → НАЗНАЧИТЬ ОБУЧЕНИЕ
1622: → КОНТРОЛИРОВАТЬ ПРОХОЖДЕНИЕ
1623: → ПОЛУЧИТЬ РЕЗУЛЬТАТЫ
1624: → ПОЛУЧИТЬ ПРОТОКОЛЫ
1625: → ПОЛУЧИТЬ ЭЛЕКТРОННЫЕ ДОКУМЕНТЫ.
1627: ОБУЧАЕМЫЙ
1628: → ПРОЙТИ КУРС
1629: → СДАТЬ ТЕСТ
1630: → ПОЛУЧИТЬ РЕЗУЛЬТАТ
1631: → ПОЛУЧИТЬ УДОСТОВЕРЕНИЕ/СЕРТИФИКАТ
1632: → СКАЧАТЬ PDF
1633: → ПОКАЗАТЬ QR.
1635: ТОО РЦОиПК
1636: → УПРАВЛЯТЬ КУРСАМИ
1637: → УПРАВЛЯТЬ ОБУЧАЕМЫМИ
1638: → ПРОВОДИТЬ ТЕСТИРОВАНИЕ
1639: → ФОРМИРОВАТЬ ПРОТОКОЛЫ
1640: → ВЫДАВАТЬ ДОКУМЕНТЫ
1641: → ВЕСТИ РЕЕСТР
1642: → КОНТРОЛИРОВАТЬ СРОКИ
1643: → АКТУАЛИЗИРОВАТЬ НПА
1644: → ПОЛУЧАТЬ АНАЛИТИКУ.
1646: ГЛАВНЫЙ ПРИНЦИП ПЛАТФОРМЫ:
1648: «ОБУЧЕНИЕ → ПРОВЕРКА ЗНАНИЙ → ДОКУМЕНТ → РЕЕСТР → QR-ПРОВЕРКА».
1650: Платформа должна быть готова к дальнейшему масштабированию, интеграции с ЭЦП, государственными информационными системами при наличии законных оснований и API, CRM, платёжными системами, WhatsApp/e-mail/SMS и мобильным приложением.
