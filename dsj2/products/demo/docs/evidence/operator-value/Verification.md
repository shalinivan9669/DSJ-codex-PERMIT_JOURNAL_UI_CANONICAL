## Существенные ограничения приёмки

Новые групповые формы проверены как DOCX и фактические PDF LibreOffice 26.2.6.3. **Открытие новых групповых форм в Microsoft Word и физическая печать — NOT RUN.** Метаданные новых версий `group-2` явно содержат `WORD_NOT_RUN`; старые сохранённые версии не переписываются. Юридическое утверждение форм эмитентом, проверка реального обучения, клиентский пилот и production-развёртывание здесь не заявляются.

V01 исполнен через настоящий браузер с сохранённым PDF. Остальные десять ежедневных сценариев имеют явную отметку API/service integration. Для V07 проверены настоящий кабинет, вход, права, загрузка/перезагрузка/скачивание внешнего документа, но весь исходный многопользовательский fixture одним операторским маршрутом не проигран. Полный G1 через 100 строк без открытия индивидуальных панелей и точное человеческое время также не измерялись. Экономия, ручные повторные вводы, ожидание заказчика и ROI остаются `null`, а не нулём.

Восстановление резервной копии выполнено; переключение работающей среды на предыдущую версию приложения не выполнялось. Порядок отката и несовместимость старого worker с новыми групповыми заданиями описаны в `docs/OT_CENTER_V2.md`. Live-интеграции с бухгалтерией, мессенджерами и государственными системами не имитируются.

## Исправление оценки уверенности после повторной сверки

AT145 ранее был ошибочно отмечен PASS общей записью о проверках прав. Фактически проверены вход работодателя по паролю, срок/отзыв membership и отзыв действующей сессии. Одноразовая ссылка-приглашение не реализована; использование просроченного/повторного invite и обращение с его token не проверены. Статус исправлен на PARTIAL, итог — 95 PASS / 89 PARTIAL. Спецификация допускает режим входа по паролю, но это не служит доказательством выполнения отдельного сценария AT145.

Оставшиеся PARTIAL включают технические операторские проверки, а не только Word, физическую печать и внешнее согласование: полный G1 через UI, сохранение/перезагрузка отдельных массовых операций, полные V02–V12 пользовательские маршруты, все варианты диалогов/фокуса и откат приложения. Все 27 браузерных PASS собраны из отдельных прогонов и повторов; шесть используют mock API. Полный регрессионный набор на окончательном SHA одним запуском не выполнялся.

### QA-001 — подтверждённый открытый дефект проверки PDF-вложений

В `apps/api/src/operator-value.ts:1034` активные PDF-элементы запрещаются regex по исходным байтам. Эквивалентные имена PDF с hex-экранированием обходят этот поиск. Независимый parser распознал активное действие в безопасном тестовом PDF, который проходит текущий фильтр. Путь используется также загрузкой работодателя с правом PROPOSE. Доказательство: `assurance-pdf-validation.json`.

Проверка выполнена только в памяти с безвредным содержимым; файл не загружался в приложение, БД не изменялась, JavaScript и внешний просмотрщик не запускались. Подтверждён обход валидации, а не эксплуатация просмотрщика или утечка между центрами. Дефект остаётся открытым: этот проход проверял достоверность заявления о готовности и исправлял отчёт, код загрузки не менялся. Утверждение об отсутствии уязвимостей для текущего коммита недопустимо.
