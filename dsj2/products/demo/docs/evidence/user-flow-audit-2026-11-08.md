## Изменения интерфейса и действия

Убраны повторные объяснения автосохранения и передачи, номера редакций из обычного результата проверки и дублирующая кнопка проверки. Проверка остаётся в передаче директору и меню заявки. Технические задания файлов свёрнуты; при ошибке виден путь восстановления. Подсказка о подстановке русского названия показывается только при пустом казахском поле. Статусы и даты уведомлений разделены. Для черновика решения нет постоянного нового баннера: сообщение появляется только при ошибке сохранения.

Для подготовленной заявки передача директору требует одного нажатия без повторного ввода. В комиссии должности не вводятся вручную. После восстановления назначения люди, группа и период не вводятся заново. Первичная подготовка, вход и настройка посчитаны отдельно: [измеренные действия](user-flow-audit-20261108/observed-routine-actions.json).
