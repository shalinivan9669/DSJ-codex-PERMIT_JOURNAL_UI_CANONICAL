# A21: реальные календарные даты через браузер и печать

PASS: четыре новые синтетические заявки; по два случая в Asia/Almaty и America/Los_Angeles. Для високосного случая дата документа 2028-02-29, протокола 2028-02-28; для границы года документ 2027-01-01, протокол 2026-12-31. Форма ps-witness v11, renderer5, настоящий локальный UI3200/API4200 и worker. Chrome152, LibreOffice26.2.6.3.

Ввод выполнен в UI. После сохранения и reload значения полей сверены с ожиданием; затем через UI оформлен комплект, скачаны настоящие DOCX/PDF/XLSX/ZIP с проверкой API SHA. Даты сопоставлены с draft и immutable issuance snapshot. После выпуска ещё один UI reload сохранил обе даты. Intl timezone и midnightProbe доказывают разные локальные календарные дни около UTC-полуночи; замена часового пояса не сдвинула date-only поля.

`date-roundtrip-proof.json` содержит 48 проверок конкретных XPath DOCX и 16 проверок RU/KZ областей конечного PDF, включая bbox найденной даты. В блоках выдачи дополнительно проверено отсутствие подставленной даты протокола. Все 8 страниц отрендерены и просмотрены; `visual-review.json` фиксирует SHA. Snapshot сохранён в issued-response.json каждого случая. printed documentDate намеренно отличается от технического времени фактического события issuance.

Первоначальная ошибка helper — попытка открыть «Новая заявка» прямо из оформленного редактора — сохранена в sibling date-roundtrip-browser.log и date-0-year/failure.txt. До создания второй заявки скрипт остановился. Исправлен только навигационный helper: переход к /requests; выполнено ровно четыре заявки без дублирования первой. Runtime, templates, issuer и настройки нумерации не изменялись. Бизнес-номера синтетических выпусков штатно присвоены сервером.

Воспроизведение: из корня продукта `node .runtime/date-roundtrip.mjs` с DEMO_E2E_PASSWORD в окружении, затем bundled Python `.runtime/date-roundtrip-audit.py`. Сохранённый helper не дублирует случаи, для которых уже есть result.json. Полная повторная независимая проверка требует нового evidence directory. Код helper/audit скопирован сюда без пароля.
