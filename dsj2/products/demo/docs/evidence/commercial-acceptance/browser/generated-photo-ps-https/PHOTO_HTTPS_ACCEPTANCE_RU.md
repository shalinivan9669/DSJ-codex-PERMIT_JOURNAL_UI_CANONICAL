# Финальный выпуск ПС с созданным портретом через HTTPS

**PASS.** Chromium 152.0.7977.83: браузерный сценарий занял 19,9 с, полный запуск — 22,0 с. Создана отдельная синтетическая заявка: https://localhost:8443/requests/1f58fc84-325f-4ac1-a8cf-928290b15bc9/edit. Использована форма `ps-card` версии 15; точный SHA указан в `photo-result.json`.

Через реальный браузер выполнены вход, создание заявки, загрузка PNG, выбор кадра 3 × 4, сохранение, перезагрузка страницы с сохранённым фото, проверка, предпросмотр PDF и один выпуск. Скачаны все шесть артефактов и сверены их SHA-256. Точное нормализованное фото встроено в оба DOCX: предпросмотр и оригинал.

Оба финальных PDF-листа и три экрана просмотрены вручную. Портрет чёткий, вписан в фотополе и не перекрывает подписи. Полоса эмитента, заголовок, таблица экзаменов, М.О./М.П. и повторные блоки находятся внутри рамок. PDF не содержит пустых страниц или текста за границами листа.

Проверка HTTPS:

- Независимое соединение Node с `NODE_EXTRA_CA_CERTS` и `rejectUnauthorized=true`: TLS 1.3, `authorized=true`, HTTP 200.
- Независимое отрицательное соединение с `ca: []` отклонено с `UNABLE_TO_VERIFY_LEAF_SIGNATURE`.
- Chromium показал издателя `DEMO isolated acceptance CA` и имя `localhost`. Pin публичного ключа ограничен временным профилем браузера. Системное доверие Windows не менялось.
- `demo_session`: Secure, HttpOnly, SameSite=Strict. `demo_csrf`: Secure, SameSite=Strict. Значения cookies и токены в отчёт не записаны.

Первый отрицательный контроль ошибочно переиспользовал уже проверенное keep-alive-соединение. Диагностика сохранена в соседней папке `generated-photo-ps-https-agent-probe`; тест исправлен через `agent:false`, чтобы каждый контроль выполнял собственное TLS-рукопожатие. Ошибка случилась до создания заявки, повторного выпуска не было.

Доказательства: `photo-result.json`, `pdf-visual-review.json`, `results.json`, PNG экранов и листов, скачанные PDF/DOCX/XLSX/ZIP. Исходный портрет — вымышленный, создан ImageGen; SHA исходника и нормализованного изображения сохранены в `photo-result.json`.

Механизмы проверки описаны в [Node TLS](https://nodejs.org/api/tls.html) и [Node HTTPS](https://nodejs.org/api/https.html). Локальный сертификат действует один день. Этот сценарий доказывает работу локального HTTPS-стенда, а не внешнего домена или production.
