# Источники полей и проверка минимальных действий

Исходная точка: `e10f3f77b195953555811c0b6c2b9de622dea4d4`, ветка `codex/operator-flow-refinement-20261003`. Существовавшие незакоммиченные defaults сохраняются. Источники проверены в коде и целевых тестах; свежий UI20/Excel400, исключения и фактические PDF/DOCX завершены с границами, указанными в итоговом отчёте.

| Поля активных форм | Источник и приоритет | Проверенное поведение / граница |
| --- | --- | --- |
| ФИО RU/KZ, должность | Сохранённый человек / импорт / однократный ручной ввод; языковой fallback не является переводом | Не придумывать неизвестные данные; общая должность выбранной группе |
| Работодатель RU/KZ, БИН, адрес | Выбранная компания либо отдельный работодатель человека, затем локальное исключение | Безопасно дополнять реквизиты той же компании, не смешивать разных работодателей |
| Учебный центр, комиссия, подписанты, город | Закреплённая версия профиля | Одна ошибка настройки центра, общий переход к исправлению |
| Программа, часы теории/практики | Курс и категория → профиль/общие настройки → событие → защищённое исключение | Пустой placeholder не стирает default; WORKER 10/16 и ИТР 40 относятся к конкретным программам |
| Дата документа | Дата создания по timezone центра → общая дата → ручное исключение | Сохранённая дата не изменяется при reload на следующий день |
| Дата протокола | Дата события/документа → явное исключение | UI, согласование и предусмотренные исходным бланком печатные поля используют одно эффективное значение |
| Начало/окончание обучения | Версия графика центра/курса и существующий календарный движок | Не вводить выдуманный универсальный график; использовать сохранённые настройки автоматически |
| Срок / следующая проверка | Подтверждённое пользователем правило: WORKER +1 год, любой ITR +3 года; ПС бессрочно | Устранить конфликт двух калькуляторов, сохранить MANUAL/IMPORTED/CLEARED; это правило продукта, а не заключение о действующем законодательстве |
| Результат обычной новой выдачи | PASSED и стандартный словесный результат курса | Автоматическое значение не меняет сохранённые UNKNOWN/FAILED/ABSENT и не выдаёт документ само |
| Отрасль ИТР | Достоверная программа/общие поля курса, иначе ввод один раз | Нет подтверждённого универсального default |
| Знания / прокторинг ИТР | Фактические общие сведения курса и индивидуальные исключения | Не придумывать баллы или внешнюю проверку; вводить общее значение один раз |
| Профессия / квалификация ПС | Явное поле курса/человека; существующий fallback общей профессии/должности | Не смешивать новую квалификацию и текущую должность без явного правила |
| Номера / основание | Связанные формы и серверный выпуск | Не запрашивать будущий внутренний номер; внешний номер вводится только при реальном основании |
| Фото / приложения | Сохранённые ссылки и требования выбранной формы | Требовать только действительно отсутствующие обязательные данные |
| Происхождение | AUTO/COURSE/INHERITED/MANUAL/IMPORTED/CLEARED | Смена курса/даты не стирает защищённые исключения; технически пустая строка не становится человеком |
| Пересдача | Явная новая попытка со ссылкой на исходную | Очистить предыдущие результаты всех языков; исходные snapshot и файлы неизменны |

Сохранение незавершённого DRAFT, явная передача директору, решение и выпуск проверяются раздельно. Репрезентативные масштабы: ручные 20 человек и один настоящий Excel на 400 человек; это не бизнес-пределы.


Итог: [IMPLEMENTATION_REPORT_RU.md](IMPLEMENTATION_REPORT_RU.md). Ручной цикл завершён по трём сохранённым этапам, не одним непрерывным зелёным E2E. Для файлов проверены 22 образца PDF/DOCX всех 11 форм и просмотрены все страницы 11 PDF-образцов (21 страница суммарно); это не визуальный просмотр всех 105 документов. Точные границы: [manual20-artifact-qa.md](manual20-artifact-qa.md).

Исторический сертификат ИТР не содержит печатных полей часов/срока; протокол ИТР не печатает отдельные поля отрасли/знаний/прокторинга. Snapshot проверен, печать отсутствующих полей не заявляется. Неизвестный фактический график центра остаётся отложенным решением пользователя; локальный синтетический график не переносится в production. Визуальные ограничения старых бланков раскрыты отдельно и не скрываются статусом генерации файлов.
