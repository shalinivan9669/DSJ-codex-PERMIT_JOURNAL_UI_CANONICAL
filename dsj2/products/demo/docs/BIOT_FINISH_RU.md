# Завершение изменений БиОТ — 22 сентября 2026

Изменения применены к локальному приложению http://localhost:3200/.
API на 4200 и worker перезапущены с текущими исходниками; worker использует
`demo-ooxml-6/libreoffice-26.2.6.3`. Web и PostgreSQL не перезапускались.
После обновления API и proxy вернули HTTP 200 на health.

## Завершённая реализация

- Явные категории БиОТ, отдельные часы теории и производственного обучения,
  сроки по категории. Старые черновики сохраняются; для нового выпуска требуется
  выбрать категорию. Категории, которым требуется сертификат ЕЦС, не оформляются
  местным сертификатом.
- Ручные часы и сроки сохраняются после повторного открытия заявки, включая
  значения, совпадающие с первоначальной автоматической подстановкой.
- Протокол связывается с подходящим удостоверением или сертификатом. Несколько
  подходящих документов и конфликт введённого номера со связанным документом
  отклоняются до регистрации.
- Установлены worker v16, специальный сертификат v14, протокол рабочих v10
  с семью колонками и протокол ИТР v1 с десятью колонками. Каталог содержит
  11 форм. Полоса с названием выдающего центра сохранена. Семь остальных
  шаблонов не изменили SHA-256.
- Фотографии PNG/JPEG проверяются по сигнатуре до вызова нативного декодера.

## Граница результата

По повторному указанию пользователя оставшиеся проверки остановлены.
Два браузерных сценария черновиков и новый выпуск четырёх форм через UI после
обновления runtime **не запускались**. Новый тестовый центр или профиль для них
не создавался. Полный integration, нагрузка и новая сборка контейнеров в этом
этапе не выполнялись. Результат относится к локальному приложению на 3200;
отдельная контейнерная установка на 8443 в этом этапе не обновлялась.
Физическая печать и утверждение уполномоченным эмитентом не подтверждены.

Очистка Git закреплена отдельным коммитом `30eeb00`: 956 генерируемых файлов
перестали отслеживаться, все сохранены на диске. Исходные шаблоны, шрифты,
fixtures и лицензии остаются в репозитории.
