## Метод аудита

Проверены текущие исходники создания заявки, редактора, карточки человека, общих полей, импорта, групповых операций, автосохранения и проверки. Сопоставлен исторический строковый интерфейс frozen DSJ `apps/web/components/biot-card-generator.tsx` с текущим DEMO. Исторический модуль не переносился: вместе с ним вернулись бы ручные номера и избыточно широкая таблица.

Применены навыки `ui-ux-pro-max` и `frontend-design`. Принципы сверены с [W3C: интерактивные таблицы и клавиатура](https://www.w3.org/WAI/ARIA/apg/patterns/grid/) и [Carbon: таблицы, поиск и массовые действия](https://carbondesignsystem.com/components/data-table/usage/). Использована нативная HTML-таблица с настоящими полями; роль ARIA grid не объявляется без полного поведения grid. Tab сохраняет обычный доступ ко всем действиям, Enter/Shift+Enter дополняют его переходами по колонке.

Визуальное решение сохраняет существующий язык продукта: Segoe UI, белая рабочая поверхность `#ffffff`, фон `#f0f4f6`, текст `#233e50`, линии `#d5e0e5`, акцент `#087b80`, ошибки `#ad3047`. Один человек — одна компактная строка; цвет выделяет выбранную строку, фокус или ошибку. RU/KZ и дополнительные идентификаторы раскрываются по необходимости.

## Рабочий сценарий

1. Создать заявку и выбрать комплект. Общие сведения обучения задаются для группы; отдельные даты и исключения остаются в карточках.
2. В таблице вводить ФИО, должность и место работы. Tab — следующее поле, Enter — строка ниже в той же колонке, Shift+Enter — выше.
3. При необходимости выбрать KZ или RU + KZ; скрытие колонок не удаляет значения. Табельный номер и ID включаются отдельно.
4. Для готового списка использовать импорт или вставку диапазона. Вставка следует **видимому порядку колонок**, показывает изменения и требует отдельного подтверждения замены. При активном поиске/фильтре диапазон не применяется к скрытым строкам: интерфейс предлагает сбросить фильтры.
5. Найти нужную группу, выделить видимые строки и применить общие значения через существующий предпросмотр. Индивидуальные, импортированные и явно очищенные исключения сохраняют прежние правила.
6. Выполнить проверку. Можно последовательно исправлять строки с замечаниями; после исправлений запустить проверку повторно. Карточка открывается по кнопке документов или ссылке на ошибку.
