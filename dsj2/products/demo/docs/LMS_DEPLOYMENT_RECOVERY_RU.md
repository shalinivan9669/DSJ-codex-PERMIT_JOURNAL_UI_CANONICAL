# Восстановление доступа к обучению

`LMS_DEPLOYMENT_REVIEW_REQUIRED` означает, что сервер не нашёл подходящее подтверждение настройки для центра с `demoOnly=false`. Он закрывает работу с данными слушателей: назначения, группы, календарь, работы, результаты, выдачу и общую библиотеку файлов с записями занятий. Изменение роли и очистка браузера не устраняют причину.

Подготовка программ доступна до подключения слушателей: сотрудники с соответствующими правами могут читать и создавать программы, сохранять черновики, готовить вопросы, читать нормативные источники, согласовывать и публиковать версию. Публикация программы не открывает её назначение слушателям. Штатные права на чужие курсы, роли, согласование и tenant isolation продолжают действовать; это не разрешение хранить персональные данные в учебном контенте.

Директор, администратор или суперадминистратор открывает **Настройки → Пользователи → Доступ к обучению**. Проверка читает состояние сервера и не меняет настройки. «Скопировать задание» содержит идентификатор своего центра и причину блокировки; передать задание специалисту нужно отдельно. Методист видит причину и обращается к администратору.

## Действия ответственных

1. Ответственный за данные центра проверяет подтверждения размещения данных и всех копий, основания обработки, доступ, сроки хранения, учёт субъектов и процедуру инцидентов/удаления. Техническая проверка полноты не подтверждает юридическую действительность документов.
2. Специалист сервера подключает к сервису API переменную `DEMO_LMS_DEPLOYMENT_EVIDENCE`: абсолютный путь к закрытому UTF-8 JSON-файлу, доступному процессу сервиса. Максимальный размер — 256 KiB. Это массив записей по центрам. При изменении окружения нужен штатный перезапуск соответствующего сервиса; изменение доступного файла перечитывается при следующей проверке. Все процессы, проверяющие этот запрет, должны иметь согласованную настройку.
3. Для своего `tenantId` запись должна соответствовать `packages/contracts/src/lms/deployment-gates.ts`. Обязательные поля: `operator`, `approvedBy`, `approvalReference`, `lawfulBasis`, `subjectAccountingReference`, `retentionPolicy`, `incidentAndDeletionProcedure`, `inventory`.
4. В `inventory` нужны ровно по одной записи `DATABASE`, `REPLICAS`, `FILES`, `BACKUPS`, `TEMP`, `RENDER_CACHE`, `QUEUES`, `LOGS`, `EXPORTS`, `EVIDENCE`, `SUBPROCESSORS`. В каждой: `kind`, `applicable`, `country`, `operatorOrProcessor`, `evidence`, `access`, `retention`. Для используемого хранилища (`applicable=true`) подтверждённая страна — `KZ`. Неиспользование компонента также должно иметь реальное основание. Заполнять вымышленные подтверждения или менять центр на `demoOnly=true` для обхода запрета нельзя.
5. После настройки администратор нажимает **Проверить настройку**. Статус должен стать «Обучение доступно». Методист повторно открывает программы. Обычные права на курсы, публикацию, назначения, результаты и подпись продолжают проверяться отдельно.

Для существующего Compose-развёртывания подготовлен [файл подключения и порядок применения](../deployment/lms-readiness.md). Он монтирует настоящий документ только в читающие его процессы; сведений об одобрении или размещении не создаёт.

## Значение диагностики

| Причина | Что проверить |
| --- | --- |
| Документ не подключён | Переменную окружения сервиса API. |
| Документ недоступен | Абсолютный путь, подключение закрытого файла и права процесса на чтение. |
| Неверный формат/размер | UTF-8 JSON-массив и ограничение 256 KiB. |
| Нет подтверждения для центра | Точное соответствие `tenantId`; подтверждение другого центра не подходит. |
| Подтверждение неполное | Обязательные поля, непустые значения, полный перечень без повторов. |
| Размещение не подтверждено | Фактическое подтверждение размещения каждого используемого хранилища в Казахстане. |

API диагностики: только `GET /settings/learning-readiness`, с текущей сессией руководителя/администратора центра. Клиент не выбирает центр. Ответ содержит только готовность и ограниченный код причины; пути сервера, содержимое подтверждений и сведения других центров не выдаются. Через этот endpoint нельзя загрузить подтверждение или включить обучение.
