# Контроль физической печати

Статус: **BLOCKED**. В среде проверки обнаружен только виртуальный принтер
Microsoft Print to PDF. Бумажный отпечаток и измерение не выполнялись.

Контрольный файл: `evidence/commercial-acceptance/physical-print-calibration.pdf`.
Он содержит две портретные и две альбомные страницы A4, шкалу 100 мм и четыре
метки совмещения. Все четыре страницы отрендерены и просмотрены; это проверка PDF,
а не результат работы принтера.

1. В драйвере выбрать фактический размер 100%, отключить fit/shrink, несколько
   страниц на листе, буклет и поля приложения. Указать бумагу A4.
2. Сначала напечатать страницу 1 односторонне. Измерить шкалу от 0 до 100,
   расстояния до меток и размеры листа. Записать принтер, драйвер, бумагу и результат.
3. Напечатать страницы 1–2 отдельным заданием duplex с переворотом по длинному краю.
   Сверить верх листа и четыре метки на просвет, записать смещение X/Y.
4. Отдельным заданием напечатать страницы 3–4 duplex с переворотом по короткому краю.
   Снова измерить масштаб и совмещение. Эти настройки относятся к калибровочному
   файлу; они не утверждают раскладку конкретной корочки.
5. Напечатать по одному короткому и длинному контрольному образцу каждой
   используемой формы. Проверить все ФИО RU/KZ, казахские буквы, рамки, фотографию,
   поля подписи, номера, читаемость при 100%, размеры панелей, линии сгиба/реза.
   Ничего не подрезать и не добавлять линии, которых нет в утверждённом бланке.
6. Для форм из двух страниц сначала напечатать обе страницы односторонне,
   согласовать назначение панелей/лицо/оборот и край переворота с утверждённым
   физическим бланком. Только после этого испытать duplex на одном получателе.
   Не включать его сразу для смешанного пакета разных людей.
7. Уполномоченный сотрудник фиксирует допуски размера/совмещения для конкретного
   бланка и подписывает протокол приёмки. Универсальный допуск без требований к
   физической корочке здесь не выдумывается.

Для каждой формы приложить контрольный PDF, его SHA-256, номер версии шаблона,
фотографию/скан отпечатка с линейкой, фактические миллиметры, край переворота и
подпись проверяющего. Число страниц не определяет автоматически назначение
лицевой/оборотной стороны. Нормативное утверждение проводится отдельно по
[карте правовой сверки](FORM_LEGAL_REVIEW_RU.md).
