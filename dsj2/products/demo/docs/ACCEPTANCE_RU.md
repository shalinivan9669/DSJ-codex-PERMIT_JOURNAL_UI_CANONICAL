## Конкретный внешний остаток

1. На Linux runner выполнить подготовленный CI: закреплённый PostgreSQL18.3, Docker images, их high/critical CVE gate, image runtime backup/restore и nginx/ingress. Локальная причина отсутствия результата — нет pipe `dockerDesktopLinuxEngine`.
2. Для A01 подтвердить запуск внешней standalone копии в разрешённой среде. Автоматическая проверка отклонила три команды старта с `blocked by policy`; обходной запуск не предпринимался. Установка/миграции/сборка этой копии проверены отдельно.
3. По реальному inventory выполнить `CUTOVER_ROLLBACK_RU.md`: закрыть каждый старый origin/public link, остановить непечатные workers/cron/serverless, проверить backup и отсутствие обходных доступов. Это A48 BLOCKED, а не выполненный rollout.
4. Уполномоченному сотруднику подтвердить реквизиты/формы/полномочия и выполнить физическую печать100%, масштаб/duplex/совмещение под используемый принтер. Исторический шаблон и PDF QA не заменяют это утверждение.

Автоматическая проверка разрешений также отклонила запуск legacy browser preview с `blocked by policy`; точного дополнительного основания не предоставила. Его браузерная проверка не заявляется выполненной. Доказательства HTTP boundary и исходников сохраняются отдельно.
