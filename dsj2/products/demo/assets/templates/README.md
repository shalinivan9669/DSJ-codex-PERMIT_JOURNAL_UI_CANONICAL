# Печатные формы DEMO

В `manifest.json` зарегистрированы ровно десять подключённых форм. Неиспользуемая
reference-форма не включена. Исходные размеры страниц, разделов, таблиц и векторных
рамок сохранены. Старые встроенные изображения удалены целиком, включая подписи,
печати, thumbnail, header/footer media и внешние relationships. Реквизиты,
комиссия, результаты и длительность заменены явными полями версии профиля и строки.

Активные версии перечислены в `manifest.json`: восемь исправленных форм v5,
ITR и PTM-card остаются v4. Исправления v5 перечислены в `v5-changes.json`.
Сохранённые v4 перенесены без изменения байтов в
`docs/evidence/commercial-acceptance/printing/historical-inputs/`; они не входят
в каталог активных шаблонов. В v4 были удалены вложенные двоичные кэши Word
`o:gfxdata`, содержащие прежний текст, остаток прежнего бренда «ТОО Аттестац»
и повторение эмитента в декоративных полосах. Версии 1–3 сохранены только в игнорируемом
локальном архиве разработки `.runtime/historical-template-generation`, вне поставки. Установщик
сохраняет bytes каждой версии в приватном ArtifactStore. Выпуск ссылается на ключ
и SHA-256 этой сохранённой версии, поэтому обновление каталога шаблонов не меняет
исторический документ. Все повторные скачивания идут из ArtifactStore.

Протоколы этих форм индивидуальные: одна строка получателя на документ. DEMO не
объявляет их групповыми протоколами. Номер внешнего основания вводится отдельно.
Результаты, сроки, часы и состав комиссии не выводятся из названия учебной программы.

Шрифты Liberation 2.1.5 распространяются по SIL Open Font License; лицензия и
контрольные суммы находятся в `../fonts/`. PDF создаёт LibreOffice 26.2.6.3 из
сохранённых DOCX bytes. Примеры и страницы находятся в `docs/evidence/render/`.

Нормативные формулировки существующих форм сохранены; их юридическая применимость
требует утверждения эмитентом. Геометрия исходной формы не доказывает актуальность
нормативных ссылок. В образцах есть отметка «ДЕМО — НЕ ЯВЛЯЕТСЯ ВЫДАННЫМ ДОКУМЕНТОМ».
В рабочем документе отметка не появляется из-за названия программы.

Рендерер сохраняет размеры листов, рамок и фото-слотов, заменяет длинные серии
пустых абзацев настоящими переходами страниц и переносит введённый текст внутри
существующих блоков. Фото резервирует место в текстовом блоке PB/PS/PTM. Если
текст не помещается при 8 pt, генерация возвращает `PRINT_LAYOUT_OVERFLOW`,
а не обрезанный документ. Копия второй дисциплины PS не заполняется автоматически
тем же результатом: дополнительные пустые строки исходной формы остаются пустыми.

Перед окончательным выпуском API вызывает тот же `render_one` в режиме
`preflight`, без регистрации номеров. Для текста действует общий с contracts
предел 80 символов в одном неразрывном слове. Названия и ФИО не обрезаются.
Заполнение карточек освобождает ширину только после прохождения нижнего края фото.
Минимум 8 pt относится к основным заполняемым блокам; старые декоративные полосы
и мелкие пояснения пустых повторных панелей требуют отдельной физической сверки.

У текущего исторического BIOT-протокола только первая таблица имеет строку
номеров колонок: шесть отдельных буквальных ячеек `1,2,3,4,5,6`; первая и вторая
строки повторяются на физической странице. Остальные формы не получают
придуманную строку `1..N`. Все четыре протокола индивидуальные: порядковый номер
единственного человека — `1` на каждой копии, серверный номер протокола от него
не зависит. Номер удостоверения в PS — отдельный `credentialNumber` связанного
удостоверения; подпись PTM и примечание BIOT остаются пустыми.

**Правовая приёмка BIOT — BLOCKED.** Эта инженерно исправленная историческая
структура из шести колонок не соответствует семиколоночному приложению 3,
действующему с 12.07.2026. Изменились также формы worker/ITR. См.
`docs/FORM_LEGAL_REVIEW_RU.md`; `regulatoryReview` в manifest сообщает оператору
об ограничении. Реальный уполномоченный эмитент должен утвердить нужные
действующие формы. Инженерные PASS не означают нормативное утверждение.
